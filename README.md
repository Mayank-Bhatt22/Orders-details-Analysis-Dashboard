# Orders-details-Analysis-Dashboard
Sales Orders Dashboard built in Power BI. Includes insights on top-selling products, customer segments, payment methods, state-wise revenue, category growth, and profitability contribution. Filters available by Sub-Category, State &amp; Payment Mode.

# 📊 Orders Details Analysis – Power BI Dashboard
This Power BI dashboard provides a complete analysis of order performance, revenue distribution, customer segments and category growth. The main objective of this project is to identify high-performing products, profitable regions, and understand payment behaviour across customers.

# Key Insights
• Top 10 selling sub-categories
• Customer segment with highest profit
• State-wise total revenue
• Category based on growth
• Payment method contribution
• Interactive filtering based on state, payment mode and sub-category
